# College Management System - C++

## Project Overview

A College Management System developed using C++ and Object-Oriented Programming.

The project manages basic information about students and teachers.

## OOP Concepts Used

- Classes and Objects
- Constructors
- Inheritance
- Method Overriding
- Runtime Polymorphism
- Protected Members
- Base Class Pointers

## Class Structure

Person
├── Student
└── Teacher

## Features

- Student information management
- Teacher information management
- Student roll number and program
- Teacher ID and subject
- Runtime polymorphism

## Technologies

- C++
- Object-Oriented Programming

## How to Run

Compile:

g++ college_management.cpp -o college

Run:

./college
