# Bank Management System - C++

## Project Overview

A simple Bank Management System developed using C++ and Object-Oriented Programming.

The system supports different types of bank accounts and basic banking operations.

## OOP Concepts Used

- Classes and Objects
- Constructors
- Inheritance
- Encapsulation
- Function Overriding
- Runtime Polymorphism
- Protected Members

## Class Structure

Account
├── SavingsAccount
└── CurrentAccount

## Features

- Savings Account
- Current Account
- Deposit Money
- Withdraw Money
- Display Account Details
- Interest Rate
- Overdraft Limit

## Technologies

- C++
- Object-Oriented Programming

## How to Run

Compile the program using a C++ compiler:

g++ bank_management.cpp -o bank

Then run:

./bank
